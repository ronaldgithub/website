-- backup compression · benchmark TOOL

SQL Server 2025 Backup/Restore Compression: A Benchmark Tool

SQL Server 2025 heeft drie backup-compressiealgoritmes — MS_XPRESS, QAT_DEFLATE en ZSTD — en geen enkele wint altijd. SQLBackupCompression is een kleine Windows-tool die alle elf backup/restore-combinaties naast elkaar test op een echte database: bestandsgrootte, doorvoer en CPU-verbruik in plaats van gokken, met live CPU-detectie die QAT_DEFLATE uitschakelt op niet-Intel hardware. Broncode en een gecompileerde build staan op GitHub. (Engelstalig)

Execution Plan: Adaptive Joins

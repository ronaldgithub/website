Parameter Sensitive Plans (PSP) versus Parameter Sniffing

SQL Server 2022's Parameter Sensitive Plans vervangen het ene gecachete plan door een dispatcher plus maximaal drie planvarianten, ingedeeld op cardinaliteit van de parameter. Getest op Posts.ParentId in de StackOverflow-database — een kolom waar enkele waarden duizenden matches hebben en de meeste bijna nul — krijgen de zeldzame en veelvoorkomende gevallen elk hun eigen plan, herkenbaar aan predicate_range- en QueryVariantID-markeringen in het executieplan.
